# Local raw data

Place the team's frozen Lending Club accepted-loan dataset here with this exact name:

`accepted_2007_to_2018Q4.csv.gz`

The complete local path is:

`data/raw/accepted_2007_to_2018Q4.csv.gz`

Do not rename, edit, decompress in place, commit, or push this file. The cleaning pipeline reads
it directly with gzip compression inference and never modifies it. All team members must use the
same source version; record any version change and its SHA-256 checksum in the project report.
This directory is intentionally ignored except for this README and `.gitkeep`.
